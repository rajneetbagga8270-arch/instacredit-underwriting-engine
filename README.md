\# 🏦 InstaCredit: Retail Underwriting Engine



InstaCredit is an algorithmic retail lending simulator modeling automated personal credit decisions using Fixed Obligation to Income Ratio (FOIR) and risk-based credit score pricing.



\## Features

\- \*\*Gatekeeping:\*\* CIBIL cutoff threshold (< 700 auto-decline).

\- \*\*FOIR Capacity Assessment:\*\* 50% to 60% allowable debt caps.

\- \*\*Risk-Based Pricing Matrix:\*\* 10.25% to 14.00% dynamic interest rate assignment.

\- \*\*Interactive Trajectory:\*\* Stacked Plotly principal vs. interest amortization visualization.

\- \*\*Sanction Export:\*\* Instant generation and download of loan sanction memo.



\## Tech Stack

\- Python, Streamlit, Pandas, NumPy Financial, Plotly
